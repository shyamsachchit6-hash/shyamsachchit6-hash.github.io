# Shyam Rengaraj — Resume

## Publish on GitHub Pages (free)
1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`.
3. Add your PDF resume as `resume.pdf` in the same repository.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. Replace the placeholder email, LinkedIn and GitHub URLs in `index.html`.

The site is a single responsive HTML file and does not require a build step.
